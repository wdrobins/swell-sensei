# Afterglow (Afterglow Surfboards)

Personalised surf forecasts, spot recommendations, and safety guidance.

## Local Development

1. Install dependencies: `npm install`
2. Start the app: `npm run dev`
3. Open `http://localhost:8080`

## Stack

- Vite
- React + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase

## Deployment Notes

- Primary app URL (custom subdomain): `https://app.afterglowsurfboards.com.au`
- SEO files: `public/robots.txt`, `public/sitemap.xml`
- Phone/PWA metadata: `public/manifest.webmanifest`, `index.html`
